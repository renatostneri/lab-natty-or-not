# Natural ou Fake Natty?    


1. 🛠️ Projeto de Conclusão de Curso – DIO
Este é um projeto simples e modesto, desenvolvido como parte da conclusão de um curso da plataforma DIO. O objetivo principal é demonstrar o uso básico da funcionalidade Speech to Text, utilizando um serviço gratuito disponível online para converter fala em texto.

2. 🔧 Ferramentas Utilizadas
Durante o desenvolvimento deste projeto, utilizei o recurso de Speech to Text como demonstração prática. A busca por ferramentas gratuitas foi realizada por meio de prompts na plataforma DeepSeek, que sugeriu diversas opções.

A ferramenta que escolhi e consegui utilizar com sucesso foi o site ttsfree.com, que oferece conversão de fala para texto de forma simples e gratuita. Outras alternativas apresentadas em vídeos e tutoriais não funcionaram adequadamente no meu ambiente de testes.

Este projeto tem caráter demonstrativo e foi desenvolvido com foco na aplicação prática dos conceitos aprendidos.
